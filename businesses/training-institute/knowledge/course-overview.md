# Course overview

This is a fictional training institute created for the technical assessment.

## Learning paths

The data-science path includes Data Science Foundations (DS101), an introduction to data handling and foundational concepts, and Applied Data Analytics (DS202), focused on applying analysis techniques to practical datasets.

The Python path includes Python Basics (PY101), an introduction to programming with Python, and Advanced Python (PY202), for learners with basic programming knowledge who want to develop more advanced skills.
