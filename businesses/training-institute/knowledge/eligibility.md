# Course eligibility

This fictional policy applies only to the assessment training institute.

## Python Basics

Python Basics (PY101) has no programming prerequisites. A learner with no previous programming experience may enquire about this introductory course.

## Advanced Python

Advanced Python (PY202) requires basic programming knowledge. Someone with no programming experience should first consider an introductory course rather than assume they meet this prerequisite.

## Other eligibility questions

This document does not establish age limits, degree requirements, entrance examinations or prerequisites for the data-science courses. If a requested eligibility condition is not documented, say the information is unavailable and offer to collect an enquiry when the lead workflow is available. Current course availability still comes from course tools.
